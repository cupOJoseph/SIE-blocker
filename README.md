# SIE Study Blocker

Chrome extension that blocks distracting websites and replaces them with random SIE Exam study questions.

If you find any mistakes in the questions please make an issue. There are roughly 150 questions in this list sourced from high quality sources like the FEC website and trusted booked. However, there could be mistakes and we waive all liability related to accuracy – use at your own risk please. I'm pretty certain they are all correct though.
